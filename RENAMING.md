# Provenance Geometry rename and compatibility

The active project family is named **Provenance Geometry**.

| Earlier repository | Active repository |
|---|---|
| `walkthroughwonder/discrete-jacobian` | `walkthroughwonder/provenance-geometry` |
| `walkthroughwonder/discrete-jacobian-research` | `walkthroughwonder/provenance-geometry-research` |
| `walkthroughwonder/discrete-jacobian-site` | `walkthroughwonder/provenance-geometry-site` |

GitHub redirects the earlier repository URLs after a repository rename. The
following identifiers are intentionally not rewritten:

- published Zenodo titles, citations, and DOI metadata;
- commit SHAs and content hashes;
- historical release text that quotes *The Discrete Jacobian Program*;
- machine-readable packet schema names beginning with
  `discrete-jacobian-research.`;
- stable deployed paths such as `/research/dj-assets/`.

Those strings identify already issued artifacts or compatibility contracts;
they are not the active project brand. New prose, repository links, review
requests, and presentations use **Provenance Geometry**.
